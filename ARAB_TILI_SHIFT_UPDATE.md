# Arab tili darajalari yangilanishi

Arab tili testlari quyidagicha siljitildi:

- Eski 0 daraja testlari olib tashlandi.
- Eski A1 testlari endi 0 darajaga qo'yildi.
- Eski A2 testlari endi A1 darajaga qo'yildi.
- Eski B1 testlari endi A2 darajaga qo'yildi.
- Arab tili B1 darajasi testlardan olib tashlandi; mavjud B1 o'quvchilari seed_demo ishlaganda A2 darajaga ko'chiriladi.

Deploydan keyin Railway avtomatik `python manage.py seed_demo` ishlatadi.
